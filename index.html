Домашнее задание №1

  1. С помощью команды ping на учебном сервере узнать IP-адрес веб-сервера kubsu.ru.
  2. С помощью команды nslookup узнать A-записи и MX-записи домена kubsu.ru и kubsu-dev.ru.
  3. С помощью команды whois узнать дату регистрации домена kubsu.ru и kubsu-dev.ru.
  4. C помощью SSH склонировать репозитарий со скриншотами и страницей в каталог www.
  5. С помощью программы FileZilla или любого другого клиента SFTP соединиться с учебным сервером.
